# Marvel Patel — portfolio (subtle digital edition)

Static HTML/CSS/JS portfolio. Open `index.html` in a browser or deploy the folder to Vercel as a static site. No build command needed.

## Design
Pastel lavender, pale blue and soft rainbow accents with a low-contrast technical grid, sparse circuit traces, and no distracting motion. The digital background is implemented entirely in `css/style.css` (look for “Quiet digital texture”).

## Files
- `index.html` — portfolio content and MAVTRIX link
- `css/style.css` — design and background
- `js/script.js` — mobile navigation and interactions
- `assets/headshot.png` — headshot
- `assets/marvel-patel-resume.pdf` — resume

The MAVTRIX button points to https://mavtrix-five.vercel.app/. Public access depends on the destination site's deployment settings.
